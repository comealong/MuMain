# 武器与附件：刚体挂接和坐标组合

## 查实际客户端分支

先确认是手持、背挂、左/右侧、特殊物品还是独立动画物品。插槽编号、局部轴、补偿角度和偏移属于相应资源与渲染分支，不能从另一个样例复制。

本项目的入口 `RenderLinkObject` 有不同 `Link` 分支；普通 Player 手持调用使用 `Link=false`，仍然由插槽驱动。另一分支里的背挂旋转/平移不能套到普通手持。`RenderCharacterBackItem` 可能在手持循环前改变挂接路径，因此应从实际调用处追踪，不能只看函数内部某个默认值。

项目定位入口：

- `src/source/Engine/Object/ZzzCharacter.cpp`：插槽选择、手持/背挂条件、外部父矩阵与物品动画调用。
- `src/source/Render/Models/ZzzBMD.cpp`：Animation、RotationPosition、SkinVertex 及 BodyOrigin/BodyScale。
- `src/source/Core/Math/ZzzMathLib.cpp`：AngleMatrix 的旋转顺序和单位。

源 Node 是资源索引，Blender 骨骼集合序号可能改变；按 `mu_bmd_node` 查骨名，再设置约束。其它模型要读取其自己的插槽映射。

## 组合物品自身姿态

使用列向量时，右侧变换先执行。设 P_s 为角色局部插槽姿态，I_n 为物品自身内部骨架的全局姿态，A 为当前分支确认需要的附加变换：

~~~text
B_n = P_s A I_n
v_character = B_n v_item_local
~~~

然后按客户端约定加入实例位置、BodyOrigin 和尺度。若 P_s 已在世界空间，则不能重复添加角色世界变换。角色或物品的 BoneScale、BodyScale 等需按实际代码顺序处理，不能一概在公式外再乘一个倍率。

物品顶点要按自己的 Node 先求姿态；“插槽正确”不代表可以忽略物品骨矩阵。若静态物品姿态已预烘焙到网格，就不再施加一次相同的 I_n。自带多帧动作的物品则需保留并驱动其自身动画。

确认角度单位：BMD 旋转以弧度保存，客户端 AngleMatrix 输入以度解释；当前组合顺序为 Rz Ry Rx。不要用 Blender 的显示欧拉值直接代替未确认的客户端坐标约定。

## Blender 刚体设置

一种可复用的实现是独立 Socket Empty 通过 Copy Transforms 跟随骨骼，物品 parent 到 Socket：

- WORLD/WORLD 可复制完整世界插槽变换，但须确认 Empty 的父级不会再次叠加同一变换。
- `head_tail=0` 取骨头位置；显示骨长的尾端不是源插槽原点。
- 有意令物品局部矩阵直接表达 A 时，`matrix_parent_inverse` 应与该约定一致；身份矩阵方案不携带额外“保持世界位置”的补偿。
- 身体形变修改器不作用于刚体附件。独立等比尺寸调整与身体非等比造型分别处理。
- 物品的局部偏移只能来自确认的分支或明确设计需求，不能靠反复加旋转来遮盖空间错误。

骨骼世界矩阵若带非等比尺度或剪切，Copy Transforms 也会继承它们。可用线性部分的奇异值检查各轴尺度，并与预期比例比较；需要保形时，按实际空间规则构造去剪切/等比的附件变换，同时重新核对位置。

## 挂接、握持和验证

挂接变换、手掌握柄、双手配合分别检查。新手掌应围绕实际变换后的柄轴建立掌面与指列，不能先凭外观挪剑，再把新偏移当成源规则。

独立从源角色姿态、物品姿态和客户端分支计算物品世界顶点，与 Blender 求值结果对照。只验证“对象矩阵等于脚本刚设置的矩阵”会让错误参数也通过。刚体比例正确也不证明方向或接触正确。

同时检查动作前后和帧间状态，保存后重开再核对插槽元数据、物品自身动画、实际尺度、图像和接触。实际插槽表、资源姿态数值、具体动作列表与结果保存在对应工作区，不作为通用挂接常量。
